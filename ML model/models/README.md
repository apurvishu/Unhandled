# Trained ML Models

This folder contains the trained machine learning model artifacts for the SIH 2026 freight forecasting and port congestion prediction system.

## Model Files

- `freight_forecasting_model.pkl` — Freight-rate regression model
- `congestion_forecasting_model.pkl` — Congestion-index regression model
- `congestion_risk_classifier.pkl` — MEDIUM/HIGH congestion risk classifier
- `congestion_threshold.pkl` — Decision threshold for HIGH congestion
- `model_metadata.pkl` — Model features and evaluation metadata

## Forecast Horizons

- 1–7 days
- 8–14 days
- 15–30 days
- 31–90 days
